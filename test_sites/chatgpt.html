Du sa:
Help me write a query to update the postgresql counter on the pkey id column in the table leads_llm_summaries
ChatGPT sa:

Here’s a safe one-liner to resync the sequence behind id so the next insert won’t collide:

sql
-- Set the sequence to the current max(id); the next nextval() will be max+1
SELECT setval(
  pg_get_serial_sequence('public.leads_llm_summaries','id'),
  COALESCE((SELECT MAX(id) FROM public.leads_llm_summaries), 0)
);

If you prefer to make the very next value exactly MAX(id)+1, use the 3-arg form:

sql
SELECT setval(
  pg_get_serial_sequence('public.leads_llm_summaries','id'),
  COALESCE((SELECT MAX(id) FROM public.leads_llm_summaries), 0) + 1,
  false
);

Notes
• Keep public. if that’s your schema; change it if not.
• Works for both serial and GENERATED ... AS IDENTITY columns.
• Run inside a transaction if you’re worried about concurrent inserts.
